# 冠军实验室

宝可梦冠军中文对战工具。支持双方四个独立招式的双向伤害、普通/Mega 独立形态、种族值与实际能力、每项 32/总计 66 的能力点、性格、特性、道具、当前 HP、强化、状态、天气、场地、单/双打、壁和多段命中概率。

顶部「速度线」进入独立页面（`#speed`）。双方配置与伤害页共享，支持能力点、性格、强化、讲究围巾、顺风、麻痹、天气速度特性及戏法空间。速度线表分列显示低速、零点、满速、极速、围巾和顺风；普通与 Mega 分行，Mega 的围巾列不适用。

顶部「我的队伍」（`#teams`）支持 6 个成员槽位、本地浏览器保存、云端账号保存、JSON 导入／导出和副本另存。队伍页可直接编辑六个位置的宝可梦、普通／Mega 形态、性格、特性、道具、能力点和四个攻击招式。伤害页的「载入我的队伍」列出本地与云端队伍，点击成员即载入我方；临时伤害条件与保存的队伍独立。云端按 Sites 转发的登录用户隔离；并发版本不一致时保留草稿，避免覆盖其他设备的配置。云端需要登录同一 ChatGPT 账号；本地队伍只在当前浏览器，可通过文件迁移。

## Windows 本地启动

在本目录运行 `npm install`（初次使用），然后运行 `npm run dev`，打开 http://127.0.0.1:5173 。也可双击 `启动计算器.cmd`。终端关闭后本地服务停止。

`npm run build` 构建 React 客户端和 Cloudflare Worker。`npm run preview` 只预览构建后的客户端；需要验证云端接口时使用 `npm run dev`。本地开发使用独立 SQLite 文件 `.sites-runtime/teams.sqlite` 模拟 D1 和固定预览用户，未打包到生产。生产 D1 绑定为 `DB`，schema 在 `db/schema.ts`，Drizzle 迁移在 `drizzle/`；发布时由 Sites 应用迁移。全部宝可梦图像和名称数据均已保存在项目中；Google 字体不可用时使用系统字体。

## 验证

`npm test` 验证冠军能力公式、分配限制、Mega、确定的伤害向量、天气、残血、双打、免疫、壁、要害、披带、结实、多段独立卷积、固定伤害、愤怒门牙、蛮干、一击必杀和缺少条件的招式。

Mega 专项覆盖全部 82 个形态的种族值、属性和特性；验证妖精皮肤巨声的 Normal→Fairy、1.2 倍威力和 1.5 倍本系，以及飞行皮肤、冰冻皮肤、龙皮肤与大力士。详细结果见 [Mega 检查报告](docs/mega-audit.md)。速度测试覆盖取整、等级、道具、顺风、状态、天气特性、同速、戏法空间和最低能力点。

`node scripts/browser-check.mjs`（也可直接运行 `node scripts/check-update.mjs`）使用 Windows 的 Microsoft Edge 检查四招同时计算、独立要害、Mega 特性与普通形态回退、速度控制、跨页面同步、浏览器返回、交换/重置，以及 320/390/768/1024 宽度布局。截图保存在 `verification/`，不会发布到网站。

`node scripts/check-teams.mjs` 检查本地保存／重新打开、云端跨浏览器载入、Mega 配置保留、六成员独立编辑、伤害页选队和切换成员、文件往返、损坏文件、并发冲突保留草稿及手机布局。场地专项报告见 [场地检查报告](docs/terrain-audit.md)。

## 数据与规则

- 引擎为 `@smogon/calc` 0.12.0，冠军专用 `Generations.get(0)`，固定 50 级。HP = base + SP + 75；其他能力 = floor((base + SP + 20) × nature)。
- 358 个宝可梦形态、335 个攻击招式，来自冠军引擎数据库；不保证当前赛季参赛资格，不校验宝可梦学习表。
- 双倍奉还、镜面反射、金属爆炸、复仇、喷出、围攻需要本次界面未提供的历史或队伍信息，已禁用并标注原因。
- 引擎未覆盖的愤怒门牙、蛮干和一击必杀在 `engine.mjs` 中补足；先通过引擎的非零威力探测尊重属性、特性与场地免疫。金属爪的冠军数据缺失威力、属性与分类，按标准 50 威力/钢/物理补足，并保留冠军切割标记。
- 满 HP 气势披带与结实对单次命中保留 1 HP；多次命中按独立随机数求和，忽略未命中的概率。理论伤害区间显示保护前数值。结实阻止一击必杀；破格可绕过结实。
- 自动天气和场地的入场顺序已计入速度等级、讲究围巾与状态；同速、已有天气/场地和顺风影响入场顺序时仍需手动指定。双打范围招式默认存在多个目标。
- 四招均独立使用相同初始状态，不表示连续四次攻击；每个槽位独立保存要害与命中次数。伤害区展示实际转换后的属性，并单独说明特性威力修正与本系加成，不重复乘入已由引擎处理的修正。
- 速度先手判断仅在同招式优先度且无其他出手顺序修正的前提下成立。最低速度能力点按当前形态、性格和速度修正条件推测，并提示 66 点预算不足时须回收其他能力点；相同速度不计为严格超速。
- 不含回合末天气、回复、反伤和后续回合；不含未提供输入的搭档特性效果（友情防守可显式设置）。
- 浏览器 WebMCP API 可用时提供只读 `calculate_current_matchup` 工具，读取与界面相同的双向结果。当前环境未提供原生 WebMCP 验证上下文。

名称：[PokéAPI](https://github.com/PokeAPI/pokeapi)。图像：[PokéAPI sprites](https://github.com/PokeAPI/sprites) 和 [Pokémon Showdown](https://play.pokemonshowdown.com/sprites/dex/)。伤害引擎：[Smogon](https://github.com/smogon/damage-calc)。形态元数据：[pkmn/dex](https://github.com/pkmn/dex)。项目未复用其他计算器的页面或代码。
