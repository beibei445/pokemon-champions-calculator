# 场地招式检查

2026-10-01，针对当前安装的 `@smogon/calc` 0.12.0 冠军专用机制（`Generations.get(0)`）检查。结论来自机制源码、独立等效威力对照和回归测试，不代表游戏内逐次实测。

| 条件 | 结果 |
| --- | --- |
| 广域战力：使用者接地、精神场地 | 80 基础威力 × 1.5 招式修正，叠加场地约 ×1.3；等效对照威力 156。再按实际属性计算本系和克制 |
| 广域战力：双打且满足以上条件 | 变成群攻，按多个目标的 ×0.75 群攻修正计算 |
| 广域战力：使用者未接地 | 没有上述威力／场地加成，不变群攻；目标是否接地不影响使用者触发 |
| 电力上升：电气场地且目标接地 | 70→140；一般电气场地增伤还要求使用者接地，两项条件分别判断 |
| 大地波动：存在场地且使用者接地 | 50→100，并按场地变为电／草／妖精／超能力；电／草／超能力还可获约 ×1.3 场地修正，薄雾没有一般妖精增伤 |
| 薄雾炸裂：薄雾场地且使用者接地 | 100→150；没有一般妖精场地加成，双打群攻仍 ×0.75 |
| 普通电／草／超能力攻击 | 使用者接地时，对应场地采用 `5325/4096` 定点修正（界面简记 ×1.3） |
| 薄雾场地、接地目标受到龙系伤害 | ×0.5；未接地目标不减伤 |
| 青草场地、接地目标受到地震／重踏 | ×0.5；大地之力不减伤 |
| 铁滚轮、没有场地 | 招式失败，0 伤害；有任一场地时可发动。本次攻击后场地消失不传播给其他独立招式槽位 |
| 精神场地与先制攻击 | 只保护接地目标；飞行等未接地目标不受该保护 |
| 青草滑梯、使用者接地且青草场地 | 55 基础威力、一般草系场地加成、先制度 +1；会被女王的威严／尾甲阻挡 |

接地判定覆盖飞行属性、漂浮／浮游、气球、黑色铁球、重力；失效的道具先由引擎处理。精神制造者的自动场地与手动精神场地结果一致。

## 修复与界面

主要场地威力、属性转换及群攻机制原本已经正确。发现冠军引擎遗漏了青草滑梯的条件先制度，导致原先无法被女王的威严／尾甲阻挡；应用现在在计算前补入先制度，继而使用引擎原有的免疫判断。修复不改变未接地或非青草场地时的招式。

招式槽位、伤害结果与「计算条件」现在展示招式场地威力修正、一般场地增伤、群攻修正、双方接地情况、场地减伤与先制度。这些说明不会再乘一次伤害。双打仍假定群攻场上有多个目标；只剩一个可选目标时的场景未提供单独输入。

新增 15 项场地专项测试，包含独立构造的 156 威力单体／群攻攻击对照、四种场地大地波动，以及接地与免疫的正反例。与既有机制、队伍保存及并发校验合计 57 项测试通过。
