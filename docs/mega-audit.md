# Mega 特性与伤害检查

检查对象为项目锁定的 `@smogon/calc` 0.12.0 冠军专用引擎 `Generations.get(0)`，不是跨世代通用公式。82 个 Mega 形态的数据与该引擎逐项核对，种族值、属性、特性和 Mega 石均一致；切换形态时界面同步切换特性。

## Mega 沙奈朵的妖精皮肤

现有引擎已正确处理三个步骤：

1. 把一般系巨声变为妖精系，按妖精系计算克制与免疫。
2. 妖精皮肤给原始威力 90 施加 1.2 倍修正，对应单独生效时的威力 108。
3. Mega 沙奈朵具有妖精属性，因此计算 1.5 倍本系加成。

示例：Mega 沙奈朵，内敛，特攻 32 点，特攻实数 238；防守方烈咬陆鲨，HP 32 点、特防 32 点、慎重，HP 215、特防 150；无天气、单打、未要害。巨声伤害为 **194–230（90.2%–107.0%）**，一击倒下概率为 **43.75%**。

16 个实际伤害为：194、198、198、200、204、206、210、210、212、216、218、218、222、224、228、230。该数组与同面板、去除妖精皮肤、直接指定妖精属性和 108 威力的独立控制计算完全一致。

旧界面只显示原始招式属性和威力，会造成「没有考虑特性」的印象。此次将原始→实际属性、特性 ×1.2 和本系 ×1.5 明确显示；计算保持引擎只应用一次修正。天然妖精系月亮之力不会再次获得妖精皮肤的 1.2 倍加成；普通沙奈朵的巨声仍为一般系。

## 其他回归检查

- Mega 暴飞龙：飞行皮肤，一般→飞行、1.2 倍威力、1.5 倍本系。
- Mega 冰鬼护：冰冻皮肤，一般→冰、1.2 倍威力、1.5 倍本系。
- Mega 大力鳄：冠军特性龙皮肤，一般→龙、1.2 倍威力、1.5 倍本系。
- Mega 大嘴娃：大力士伤害与同面板、显式双倍攻击值的控制计算一致。
- Mega 喷火龙 Y：日照天气与伤害原有回归向量继续通过。
- 巨声对幽灵目标：普通一般系免疫；妖精皮肤转换后可造成伤害。
- 气象球天气转换不误标为无关的宝可梦特性。

测试在 `tests/mega-speed.test.mjs` 与 `tests/engine.test.mjs`。界面另验证 Mega/普通来回切换，特性选项与转换提示同步更新。以上核对范围是实现和引擎数据，并非声称对每个形态进行了游戏内实测。
